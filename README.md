# Radial : téléchargements

Versions publiées de Radial, la roue d'actions pour l'Explorateur Windows.

Dans [la dernière version](https://github.com/Stralcops/radial-releases/releases/latest) :

- **`Radial-Setup-X.Y.Z.exe`** (recommandé) : installe Radial pour votre compte, sans droits administrateur,
  avec un raccourci dans le menu Démarrer et le lancement au démarrage de Windows. Désinstallation depuis
  Paramètres > Applications.
- **`Radial-X.Y.Z.zip`** : version portable, à décompresser où vous voulez (pensez à « Débloquer » le zip dans
  ses propriétés avant de l'extraire), puis lancez `radial.exe`.

Radial n'est pas encore signé : Windows SmartScreen peut afficher « Windows a protégé votre ordinateur » ;
choisissez « Informations complémentaires » puis « Exécuter quand même ».

Les fichiers `.sha256` permettent de vérifier les téléchargements ; Radial s'en sert aussi pour proposer ses
mises à jour.
