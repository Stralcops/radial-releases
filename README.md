# Radial : téléchargements

Versions publiées de Radial, la roue d'actions pour l'Explorateur Windows.

Téléchargez le dernier `Radial-X.Y.Z.zip` dans [Releases](https://github.com/Stralcops/radial-releases/releases/latest),
décompressez-le où vous voulez et lancez `radial.exe`. Le fichier `.sha256` à côté permet de vérifier
le téléchargement ; Radial s'en sert aussi pour ses mises à jour.
